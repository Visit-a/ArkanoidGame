### Задание 2.1 — State

Паттерн **State** позволяет изменять поведение объекта в зависимости от его текущего состояния.

В примере для банкомата используются:
- `ATM` — контекст, который хранит текущее состояние;
- `IAtmState` — интерфейс состояний;
- `NoCardState` — карта не вставлена;
- `CardInsertedState` — карта вставлена;
- `PinVerifiedState` — PIN-код подтверждён.

### Задание 2.2 — Memento

Паттерн **Memento** позволяет сохранять состояние объекта и восстанавливать его позднее.

В примере редактора:
- `EditorDocument` — документ, состояние которого сохраняется;
- `DocumentMemento` — снимок текста документа;
- `History` — хранит историю изменений и выполняет Undo/Redo.

### Задание 2.3 — Prototype

Паттерн **Prototype** позволяет создавать новые объекты копированием готовых прототипов.

В примере:
- `Enemy` — общий интерфейс врага с методом `Clone()`;
- `BasicEnemy`, `FastEnemy`, `TankEnemy` — типы врагов;
- `EnemySpawner` — выбирает прототип и создаёт его копию.

### Задание 3 — Arkanoid

Подготовлены примеры компонентов для расширения игры:

- **Observer:** `ScoreSubject` уведомляет подписчиков об изменении счёта; `ScoreText` отображает обновлённое значение.
- **Memento:** `GameMemento` и `SaveManager` предназначены для сохранения и загрузки состояния игры.
- **Бонусы:** `BonusManager` управляет появлением и обновлением бонусов. Подготовлены эффекты `FireballEffect`, `FragileBlocksEffect` и `PlatformBoostEffect`.
